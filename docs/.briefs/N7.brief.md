## Contrato `strategy_key` (escolha)

**Ponto de anexo: worker, não Gate A persist.**

1. `signal_events` **não** ganha coluna (schema 001 congelado neste sprint).
2. `src/signal_copy.py` `ALLOWED` inclui `strategy_key` (opcional). Ausente continua válido para HMAC legado. Presente entra no canonical payload (nova assinatura).
3. `src/tradingview_worker.py` depois de `validate` OK: se o dict não tem `strategy_key` e `provider` é `tradingview`, define `signal_copy` (equivalente ao persist hardcoded atual). Qualquer outro provider sem chave → Gate B `STRATEGY_KEY_REQUIRED`.
4. Gate B **não** infere chave. Lê `signal['strategy_key']`.
5. `paper_gateway_queue.persist_risk_decision` grava `signal['strategy_key']`, nunca o literal `'signal_copy'`.
6. `docs/api-spec.yaml` `SignalEventInput.strategy_key` já é opcional — alinhar texto ao default do worker.
